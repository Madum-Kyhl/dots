# .dots

A minimal, raw-HTML (WIP) task workspace.

## Running Locally

Because modern browsers block local file loading (`file://`) via CORS security policies, serve the directory locally using one of these zero-config methods:

- **Node.js:** (Recommended as it serves LAN network as well) Run `npx serve` in the project root. (To install run `winget install OpenJS.NodeJS.LTS`)
- **VS Code:** Install the *Live Server* extension by Ritwick Dey, right-click `index.html`, and select *Open with Live Server*.
- **Python:** Run `python -m http.server 3000` in the project root.
